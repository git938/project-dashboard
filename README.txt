PROJECT WORKSPACE

Open dist/index.html in your browser to use this dashboard locally.

Planning views are available in the sidebar:
- Work breakdown: expand projects and work packages, add tasks, and track completion.
- Kanban board: drag cards between columns or use each card's status menu.
- Gantt chart: switch day/week scale and click a task to change its dates.

Tasks, status, assignees, projects, and dates stay synchronized across all three views.
Use the project filter and task search to focus your plan.

This is an interactive sample workspace. Changes last for the current page session
and reset when you reload or close it. There is no shared database or team sync.
The optional Google font uses the internet; the dashboard also works with system fonts.
